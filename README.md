# Flow Finance

Quero que você crie para mim um aplicativo de controle financeiro pessoal para iPhone, com visual moderno, bonito, minimalista e profissional, mas principalmente muito fácil e rápido de usar.

Quero ter controle completo da minha vida financeira dentro do aplicativo.

1. Tela inicial

Quero um dashboard mostrando de forma clara:

Saldo total

Quanto entrou no mês

Quanto saiu no mês

Quanto sobrou

Gastos do mês

Patrimônio total

Reserva de emergência

Progresso das minhas metas financeiras

Resumo dos cartões de crédito

Gráficos simples e fáceis de entender

Tudo deve ser atualizado automaticamente em tempo real conforme eu adicionar ou editar informações.

2. Receitas e despesas

Quero poder cadastrar:

Receitas

Despesas

Valor

Data

Categoria

Descrição

Observação

Forma de pagamento

Quero poder editar ou excluir qualquer lançamento posteriormente.

As categorias devem ser totalmente editáveis.

3. Cartões de crédito

Quero uma área específica para meus cartões.

Inicialmente quero cadastrar meu cartão Nubank, o cartão roxinho.

Para cada cartão quero poder informar:

Nome do cartão

Limite total

Limite disponível

Dia do fechamento

Dia do vencimento

Fatura atual

Faturas futuras

Compras parceladas

Quantidade total de parcelas

Quantidade de parcelas restantes

Valor de cada parcela

Data da próxima parcela

Quando eu fizer uma compra parcelada, quero que o aplicativo distribua automaticamente as parcelas nas próximas faturas.

Quero visualizar claramente quanto já comprometi das minhas próximas faturas.

Também quero poder adicionar outros cartões futuramente.

4. Parcelamentos

Quero uma área para visualizar todos os parcelamentos.

Exemplo:

Compra: iPhone
Valor: R$ 3.600
12 parcelas de R$ 300
6 parcelas pagas
6 parcelas restantes

O aplicativo deve mostrar quanto ainda tenho comprometido e em quais meses essas parcelas vão aparecer.

5. Patrimônio

Quero acompanhar meu patrimônio total.

Quero poder cadastrar manualmente:

Dinheiro

Conta bancária

Carteira

Investimentos

Veículos

Outros bens

Também quero poder editar os valores.

Quero visualizar a evolução do meu patrimônio ao longo do tempo através de gráficos.

6. Reserva de emergência

Quero uma área específica para minha reserva de emergência.

Quero informar:

Valor atual

Meta

Quantos meses de despesas quero cobrir

O aplicativo deve mostrar automaticamente quanto já alcancei da meta.

Exemplo:

Reserva de emergência
R$ 15.000 / R$ 20.000
75%

7. Metas financeiras

Quero poder criar várias metas.

Exemplos:

R$ 100.000 de patrimônio

Comprar uma moto

Viagem

Reserva de emergência

Comprar um carro

Cada meta deve ter:

Nome

Valor objetivo

Valor já acumulado

Prazo

Progresso

Quanto falta

Tudo deve ser editável.

8. Edição completa

Quero que praticamente tudo seja modificável dentro do aplicativo.

Quero poder editar:

Categorias

Cartões

Limites

Datas

Metas

Valores

Patrimônio

Reserva

Lançamentos

Parcelamentos

Configurações

Não quero informações travadas que eu não consiga alterar.

9. Facilidade de uso

Essa é uma das partes mais importantes.

Eu quero conseguir registrar uma despesa em poucos segundos.

Exemplo:

APERTO +
R$ 35
Alimentação
Nubank
Salvar

E pronto.

Não quero precisar preencher dez campos para registrar um gasto simples.

10. Visual

Quero um design:

Moderno

Elegante

Masculino

Minimalista

Profissional

Com animações suaves

Fácil de entender

Otimizado para iPhone

Quero usar cards, gráficos, indicadores de progresso e ícones.

Não quero uma interface poluída.

11. Atualização automática

Sempre que eu:

Adicionar uma despesa

Adicionar uma receita

Pagar uma parcela

Alterar uma fatura

Alterar meu patrimônio

Alterar uma meta

Alterar minha reserva

Todos os valores relacionados devem ser recalculados automaticamente.

12. Segurança

Quero que futuramente o aplicativo tenha:

Face ID

Touch ID quando disponível

Proteção dos dados

Backup

Sincronização entre meus dispositivos

13. Estrutura do aplicativo

Quero inicialmente quatro áreas principais:

INÍCIO
Lançamentos
Cartões
Metas

E uma área “Mais” para:

Patrimônio

Reserva de emergência

Orçamentos

Gráficos

Configurações

Quero que você pense como um desenvolvedor profissional de aplicativos financeiros e construa a estrutura de forma que seja fácil adicionar novas funções futuramente.

Não quero apenas uma demonstração visual. Quero uma base funcional, com banco de dados, cálculos automáticos, edição, exclusão e persistência dos dados.

Priorize nesta ordem:

Facilidade de uso

Controle financeiro completo

Atualização automática

Visual bonito e moderno

Flexibilidade para editar tudo

Segurança e privacidade

Crie o aplicativo pensando em uma experiência real de uso diário no iPhone.



Quero que o app seja dark
